# Changelog

All notable changes to ProcWitness are documented here.

## 0.9.0

- Unified instant and time-window risk scoring with publisher-aware suppression.
- Added launch context, persistence inventory, baselines, headless CLI and read-only MCP tools.
- Added opt-in direct AI reports with secure key storage and per-request consent.
- Added English and Turkish localization for the application, findings, local reports and prompts.

## 0.5.0

- Renamed from AI Scanner to ProcWitness.
- Updated application, package, installer, local data, and repository identities.
- Added one-time migration of existing local evidence into the ProcWitness data directory.
